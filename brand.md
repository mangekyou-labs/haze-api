# Brand — Haze Credits

_Status: palette deferred_

The product name is **Haze Credits**. Its logo uses a white **H** in the
existing indigo-to-cyan rounded square. Use this name in the header, landing
hero, footer, and page metadata. Stripe checkout uses Stripe purple (#635BFF)
for its payment button and selected amount; other controls retain the existing
application palette.

The project is using the neutral dark palette already established in the
application. Product copy and UI decisions in this migration use Base,
USDC, private prepaid credits, and x402 terminology without introducing a
second accent system.
