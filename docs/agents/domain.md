# Domain docs

Before exploring or changing a domain, read `CONTEXT-MAP.md` and the relevant
context file. The Base ZK Credits pilot glossary is at
`docs/wayfinder/base-zk-credits-pilot/CONTEXT.md`. Check relevant design records
and ADRs under `docs/wayfinder/` and in the package being changed. If a domain
term is absent from the glossary, use the project's existing language and
record a glossary gap when it reflects a real modeling decision.
