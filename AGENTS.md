# Repository guidance

## Agent skills

### Issue tracker

Issues and specs live in GitHub at `mangekyou-labs/haze-api`; pass `--repo mangekyou-labs/haze-api` because this checkout also has an `origin` remote. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical labels `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This monorepo uses a multi-context map. Read the relevant context before changing domain behavior. See `docs/agents/domain.md`.
